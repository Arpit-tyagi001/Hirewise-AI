# HireWise AI

Premium React + TypeScript frontend prototype for AI-powered resume parsing and ATS analysis.

## Run locally

```bash
npm install
npm run dev
```

## Open without a development server

After building, open `index.html` in this folder. It redirects to the self-contained production build in `dist/app.html`.

The app includes an interactive landing page, dashboard, candidate upload flow, ATS result view, candidate table, pricing, about, contact, responsive navigation, and a light/dark appearance toggle. All content uses polished mock data and is ready to connect to APIs.
