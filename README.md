## 📖 About

HireWise AI is a modern AI-powered platform designed to simplify resume analysis for both job seekers and recruiters.

The platform aims to:

- 🎓 Help students improve ATS compatibility
- 📄 Analyze resumes intelligently
- 💼 Match resumes against job descriptions
- 🤖 Provide AI-powered resume improvement suggestions
- 📊 Give recruiters a clean dashboard to manage candidates efficiently

> ⚠️ **Current Status**
>
> The current version is a frontend prototype powered by synthetic data.
> Backend integration, AI-powered analysis, and resume parsing are currently under development.

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/hirewise-ai.git
```

Go inside the project

```bash
cd hirewise-ai
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Visit

```
http://localhost:5173
```
